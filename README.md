# gsm-game-voice

Плагин для **GameSentenceMiner**: сам находит в файлах игры точную озвучку реплики, чистит OCR-мусор из карточки и добивает недостающий звук своей озвучкой или нейронкой.

Никаких отдельных программ и `.bat`-файлов: всё живёт внутри GSM и запускается его планировщиком.

---

## Что делает

Для каждой новой карточки в Anki (те, что добавлены сегодня):

1. **Точный звук из игры.** Если реплика есть в данных игры — в поле звука предложения подставляется настоящий файл озвучки (`dnb093.ogg` и т.п.), а не обрезанный клип из OBS.
2. **Чистка текста.** Из `Sentence` и `SentenceFurigana` убираются метки окна игры, имя говорящего и название игры (`会話タッチ`, `でんぶ先輩`, `合体攻略…`), которые OCR затаскивает в текст.
3. **Теги.** `voice::exact` + `voice::rpgmaker` / `voice::renpy` — звук взят из игры; `voice::no-source` — файла нет; `voice::game::<игра>` — из какой игры карточка; `voice::word` — озвучено слово.
4. **Озвучка слова.** Сначала из своего войс-пака (если указан), потом — GPT-SoVITS через [AnkiVoice](https://github.com/Karuma411).
5. **Нейронка вместо мусора.** Если точной реплики нет, а OBS-клипа тоже нет — предложение синтезируется нейронкой (GPT-SoVITS, голос из `voices.json` AnkiVoice).

Всё это повторяется раз в минуту, пока открыт GSM.

---

## Почему звук не перепутается

Главная проблема таких плагинов — «звук от соседней реплики». Здесь три независимые проверки:

1. **Два варианта привязки.** В данных RPG Maker команда `Play SE` может стоять как до текста, так и после него. Плагин строит обе карты («after» и «before») и считает корреляцию «длина текста ↔ длительность файла». Побеждает тот вариант, который подтверждается данными.
2. **Фильтр длительности.** Реплика должна звучать примерно 0,09–0,45 секунды на символ. Короткие `Play SE` (клики, свистки, шаги) отбрасываются.
3. **Проверка на слух (Whisper).** Плагин берёт выборку файлов из построенной карты, распознаёт их через `faster-whisper` и сравнивает текст с тем, к которому файл привязан. Если совпадения нет — пробует другой вариант привязки, а если и там нет — **не трогает карточки этой игры вообще** и пишет предупреждение в лог.

Итог: лучше оставить клип OBS, чем подставить чужой голос.

## Требования

- Windows + [GameSentenceMiner](https://github.com/beangate/GameSentenceMiner) (проверено на 2026.10.3) с включённым AnkiConnect.
- Anki запущен, в настройках GSM указан путь к Anki.
- Для озвучки нейронкой: [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) + [AnkiVoice](https://github.com/Karuma411) (пайплайн `voice_pipeline.py`).
- Для проверки на слух: пакет `faster-whisper` в питоне движка GPT-SoVITS (он там уже есть в большинстве сборок). Модель `large-v3-turbo` скачается автоматически при первом запуске (~1.6 ГБ).

Сам плагин дополнительных пакетов не требует — только стандартная библиотека Python и `ffmpeg` (тот, что ставится вместе с GSM).

## Установка

```bat
git clone https://github.com/Karuma411/gsm-game-voice
cd gsm-game-voice
python install.py
```

`install.py`:

- кладёт `plugin.py` в `%APPDATA%\GameSentenceMiner\plugins.py` (старый файл сохраняется как `plugins.py.bak`);
- создаёт пустые конфиги `gv_games.json`, `gv_word_audio.json`, `gv_tts.json`, `gv_asr.json`;
- переключает cron-запись `user_plugins` в `gsm.db` на `minutely`, чтобы плагин работал раз в минуту.

После этого **один раз перезапусти GSM**. Дальше ничего запускать не нужно: GSM сам вызывает плагин, сам поднимает GPT-SoVITS, когда есть что озвучивать.

Проверить, что всё работает: `%APPDATA%\GameSentenceMiner\gv_log.txt`.

## Конфиги

Все файлы лежат в `%APPDATA%\GameSentenceMiner\`.

### `gv_games.json` — какие игры индексировать

```json
{
  "games": [
    "D:\\Games\\Название игры"
  ]
}
```

Поддерживаются:

| Движок | Как определяется | Привязка звука |
|---|---|---|
| **RPG Maker MV / MZ** | есть папка `data/*.json` с командами 401/250 | автоматически: `after` или `before`, плюс проверка длительностей и Whisper |
| **Ren'Py** | есть `*.rpy` с `voice "file.ogg"` | однозначно (команда `voice` относится к следующей реплике) |

Другие движки (Unity и т.п.) индексировать бессмысленно: там нет надёжной связи «строка → файл». Такие карточки получат `voice::no-source` и озвучку нейронкой.

### `gv_word_audio.json` — свой войс-пак для слов

```json
{
  "dirs": ["D:\\voice-pack\\japanese"]
}
```

Имя файла = слово: `無茶振り.mp3`, `無茶振り_1.mp3`, `無茶振り - что-то.mp3`. Поддерживаются вложенные папки и форматы mp3/ogg/m4a/wav/opus. Если слово есть в паке — оно имеет приоритет над нейронкой.

### `gv_tts.json` — нейронка

```json
{
  "enabled": true,
  "anki_voice_dir": "C:\\Users\\<user>\\AppData\\Local\\Programs\\AnkiVoice",
  "gptsovits_root": "D:\\GPT-SoVITS\\GPT-SoVITS-XXXX",
  "voice": "",
  "mode": "both",
  "max_per_run": 10,
  "timeout_seconds": 900
}
```

- `voice` — пусто = голос по умолчанию из `AnkiVoice/app/voices.json`; можно `nanami`, `atri`, `narrator` и т.д.
- `mode` — `both` (слово + предложение), `sentence`, `expression`.
- `max_per_run` — сколько карточек озвучивать за один прогон (чтобы не блокировать GSM).

### `gv_asr.json` — проверка на слух

```json
{
  "enabled": true,
  "python": "D:\\GPT-SoVITS\\...\\runtime\\python.exe",
  "model": "large-v3-turbo",
  "samples": 8,
  "min_match": 0.5
}
```

- `samples` — сколько файлов из карты прослушивать при её построении;
- `min_match` — минимальное совпадение распознанного текста с ожидаемым;
- `enabled: false` — отключить проверку (тогда остаются только корреляция и длительности).

Результаты распознавания кешируются в `gv_asr_cache.json`, поэтому повторные сборки карты быстрые.

## Куда что пишется

| Поле Anki | Что туда попадает |
|---|---|
| `Sentence` | чистый текст реплики (без меток окна и имени говорящего) |
| `SentenceFurigana` | то же, но с фуриганой |
| `SentenceAudio` / `Sentence Audio` | файл озвучки: `gv_*.mp3` (из игры) или `tts_*.ogg` (нейронка) |
| `ExpressionAudio` / `Word Audio` | озвучка слова: из пака (`gvw_*.mp3`) или нейронкой |

Имена полей определяются по модели карточки, так что работают и `Lapis`, и `Kaishi Mining`.

## Логи и диагностика

`%APPDATA%\GameSentenceMiner\gv_log.txt` — обычный текст. Ключевые строки:

```
pairing check <игра>: after=0.84 before=-0.03 -> after     # какой вариант привязки выбран
asr check <игра>: match 0.91 on 8 sample(s)                # проверка на слух
indexed rpgmaker game: <игра> (+614 lines, skipped sound effects: 45)
WARNING <игра>: speech does not match its text (best 0.31); its cards will be left untouched
1794734496587: gv_dnb093.mp3 -> SentenceAudio (dnb/dnb093)
cleaned Sentence, SentenceFurigana of 1794734403057
```

Если видишь `WARNING … left untouched` — плагин не доверяет карте этой игры и не будет менять звук; нужно разобраться с форматом (прислать issue с куском `gv_log.txt`).

## Ограничения

- Плагин обрабатывает карточки, добавленные **сегодня** (`added:1`), чтобы не тормозить GSM. Старые можно прогнать вручную, вызвав `main()` плагина.
- AnkiConnect не умеет писать в карточку, открытую в редакторе — такая карточка обновится при следующем прогоне.
- GPT-SoVITS иногда выдаёт бред на отдельных фразах; встроенный контроль качества AnkiVoice это отбрасывает, карточка остаётся без звука (лучше пусто, чем бормотание).
- Whisper-проверка не бесплатна по времени: первый прогон качает модель, дальше распознаёт только новые файлы.
